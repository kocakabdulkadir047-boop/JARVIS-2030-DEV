TEK SATIR TAM ZINCIR (v53 - YONETICI IZNI YOK)
  hile <oyun> <alan> <sayi>  -> tek komut tam zincir: "hile oar para 100"
      adimlar: wand ac (oyunu bulur/kapaliysa baslatir) -> para filtrele
      (mevcut degeri bulur) -> RAM'e yazar (tek_atis, yedekli, <=500 adres)
      -> ne degisti dogrulama (gerekirse 'ayni' filtresi ile ikinci gecis)
      -> KENDISINE EKLE: hile notlari + kendi hafizasi + wand oturumu
  hile teksat [durum]        -> zincir durumu / son sonuc
  Ornek: "hile oar para 100" | "hile undertale hp 9999"
  Guvenlik: FREN kilitler; cevrimici/anti-cheat oyunlarda REDDEDILIR;
  600+ adres yaygin degerde yazma YOK (oyun cokme korumasi).
  v53.1: OAR gibi UE oyunlari icin UZMAN yol (hile_oar dosya okuma) +
  exe-ad NORMALIZE eslesme (tire/bosluk farki sorun degil) + 2 tur pid
  bekleme + ayrintili hata raporu (acik exe ornekleri listelenir).
  v53.2: i32 bulamazsa FLOAT (f32) tarama/yazim — UE oyunlari parayi
  float saklar; sonra 'ayni' filtresi. f32 adresleri oturuma karismaz.
  v53.3: TIP OGRENME — basarili atisin tipi hafizaya yazilir (i32/f32);
  sonraki "hile oar para 100" BILINEN tipi kullanir. FLOAT yazimda
  dondurma OTOMATIK baslar (oyun degeri geri yazarsa sabit tutar).
  hile/wand <oyun> <alan> dondur  -> son yazilan degeri adreslerde sabitler
  hile/wand <oyun> <alan> birak   -> dondurucuyu serbest birakir
  Eski 3 adimli yol hala acik: "hile ram ara/daralt/yaz".
  v53.4: DOSYA YOLU fallback — RAM tusendi ise oyunun KAPANISI beklenir
  (maks 5 dk), OAR kayit dosyalarina yazilir (yerel + bulut kopya).
  hile oar dosya <n>       -> dogrudan dosya yolu (oyun aciksa bekler)
  hile oar zengin ol [n]   -> tam zincir (varsayilan 999999)
  v53.5: TRAINER BUTUNLESME — teksat basarilari trainer'a ISLENIR
  (tip + adres + deger kalici). Artik:
  trainer <oyun> goster    -> ogrenilen RAM hedeflerini de gosterir
  trainer <oyun> uygula    -> oyun ACIKSA ogrenilen tip ile RAM'e yazar
                              + dondurma otomatik; KAPALIysa dosya yolu
  trainer <oyun> birak     -> dondurucuyu serbest birakir
  Pano/wand durum artik TIP gosterir: i32/f32 (ogrenme + dondurucu).
  v53.6: NUMPAD'LI KADEMELI KESIF (Cheat Engine "unknown initial value")
  Para degerini OKUYAMAZSA (ekrandan/oturumdan/dosyadan) zincir OTOMATIK
  kesif moduna gecer: yazilabilir RAM'den ~32 MB SNAPSHOT alinir (f32+i32
  cift gorunum), sonra SEN oyunda parayi degistirip NumPad ile soydersin:
  hile <oyun> kesif [n]  -> kesif taramasini ELLE baslat (orn: "hile oar kesif")
  NumPad 1 = para ARTTI | 2 = AZALDI | 3 = DEGISIMEDI | 0 = YAZ
    (oyun odakliyken de calisir; yazili: "hile kesif 1/2/3/0")
  hile kesif yaz <n>     -> hedef degeri tasiyan adaylara YAZ + dogrula
  hile kesif             -> durum (aday sayisi, filtre adimi, son NumPad sonucu)
  hile kesif sifir       -> snapshot + kaydi sil, bastan basla
  Kesif tamam olunca: yazim + dogrulama + tip ogrenme + DONDURMA otomatik,
  v51 hile notu + trainer'a isleme (v53.5 ayni akis). Adimlar config/
  kesif_log.txt dosyasina da dusulur; FREN kesfi de kilitler.

    /telefon              -> uygulama sayfasi
    /telefon.webmanifest  -> uygulama kimligi (tam ekran, ikon)
    /telefon-sw.js        -> cevrimdisi kabuk onbellegi
    /telefon-icon.svg     -> uygulama ikonu

  2K -> 1080p -> 720p); kamera o cozunurlukte acilir ve ekranda GERCEK
  cozunurluk + fps yazar. "AI 1920p" butonu AI'ya gidecek karenin
  genisligini secer (960 / 1280 / 1920 / 3840). Kamera 4K kalir, AI'ya
  olceklenmis kare gonderilir (bant genisligi ve hiz icin).
  7/24 NOBET: "Nobet" butonu acilinca
    - ekran Wake Lock ile kapanmaz,
    - kamera durursa (onended/hata) 2-3 sn icinde KENDI kendine geri gelir,
    - telefon ekrani kapanip acilinca kamera yeniden alinir.
  AI GORUYOR: saniyede 1 kare /api/telefon-kare ile ayni canli AI oturumuna
  gonderilir; durum satirinda "gonderilen kare" sayaci gorunur.
  PIN (iki gercek hata duzeltildi):
    1) Telefon komutlari PIN GONDERMIYORDU; sunucu PIN zorunlu tuttugu icin
       her komut 403 ile reddediliyordu. Artik uygulamada PIN kutusu var.
    2) KRITIK: PIN uretimi 'secrets.randint' kullaniyordu — secrets modulunde
       randint YOK. Bu yuzden PIN dosyasi BOS olusuyor, bos PIN kontrolu

       kaliyordu. Dogru cagri: secrets.randbelow(1000000).
    Artik PIN ACILISTA uretilir ve ekranda yazilir:
      SYS: 🔑 Telefon PIN: 052496  (dosya: config/telefon_pin.txt)
    Telefondaki PIN kutusuna bu 6 haneyi yaz ve Kaydet'e bas.

  mikrofon/kamera iznini ver, sonra menu > "Ana ekrana ekle".
  COK ADRES + DOGRU ADRES SECIMI ("web acilmiyor" cozumu):
  JARVIS acilista TUM yerel IPv4 adreslerinin linkini yazar. Artik GERCEK

  Bu makinenin DOGRU adresi: http://192.168.1.111:8766/telefon
  JARVIS sunucusu 0.0.0.0:8766 dinler (tum arayuzler) ve duvar kurallari

  ACILMIYORSA sirayla:
